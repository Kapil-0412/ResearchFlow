# ResearchFlow

ResearchFlow is an open-source research paper discovery, relevance analysis,
screening, and legitimate full-text management system.

## Project Status

🚧 Early development

## Planned Features

- Multi-source research paper discovery
- Boolean search queries
- Metadata collection
- Paper deduplication
- Relevance scoring
- Relevance explanations
- Manual paper screening
- Legitimate open-access/full-text discovery
- PDF downloading
- Organized research library
- Search checkpoints and resume support
- Citation and BibTeX export
- Future semantic relevance analysis

## Principles

ResearchFlow does not bypass paywalls, authentication, CAPTCHAs,
robots restrictions, or publisher access controls.

The project prioritizes legitimate open-access copies, repositories,
preprints, publisher-provided access, and the user's authorized
institutional access.
